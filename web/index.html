馆藏简介

cursorEnv 由四类“藏品”组成，覆盖从环境复现到智能协作的完整链路。

01

核心 Cursor 规则

项目级与全局 .cursor/rules/*.mdc，定义 Agent 的行为底线：自动路由、知识库构建、规则备份、代码探索前置图谱。

02

环境工具文档

Graphify、agentmemory、Notion MCP、Headroom 与各类 Skills 的部署指南；新机器按 cursor-env-manifest.json 复现。

03

Agency Agents 规则库

统一收录自 agency-agents 单一项目的全部专家 Agent 规则，再按领域细分，从后端架构到内容增长，按需调用。

04

机器可读清单

cursor-env-manifest.json 记录部署顺序与必要程度，支撑“最小部署”到“完整复原”的一键迁移。
