# 01 · Caveman × Ponytail 用法与命令

## 定义

Cursor 全局 skills 安装后的触发方式、强度档位与辅助命令。

## 关键结论

### Caveman 命令

| 命令 / 话术 | 作用 |
|-------------|------|
| `/caveman` · `/caveman lite\|full\|ultra` | 开启/切换简洁说话 |
| `/caveman-commit` | 短 commit message |
| `/caveman-review` | 一行 PR 评论 |
| `/caveman-compress <file>` | 压缩记忆/规则文件（后续输入更小） |
| `/caveman-stats` | 节约统计 |
| `talk like caveman` / `normal mode` | 口语开关 |

### Ponytail 命令

| 命令 / 话术 | 作用 |
|-------------|------|
| `/ponytail` · `/ponytail lite\|full\|ultra\|off` | 开启/切换懒惰强度 |
| `/ponytail-review` | 审 diff，给删除清单 |
| `/ponytail-audit` | 审整仓过度工程 |
| `/ponytail-debt` · `/ponytail-gain` · `/ponytail-help` | 债务账本 / 收益 / 帮助 |
| `be lazy` · `yagni` / `normal mode` | 口语开关 |

### 选型

| 目标 | 用 |
|------|-----|
| 回复短、读得快 | Caveman |
| 少依赖、少样板代码 | Ponytail |
| API 载荷压缩 | Headroom（非本页） |
